`~/Dev/themeforseen.com-proj/branding`.

| `logo-filled.svg` | The secondary mark. The outer silhouette alone |
| `favicon-src/cloud-logo-16px.png` | Hand-tuned at 16 px, with wider drip spacing. The master for the micro mark |
| `favicon-src/cloud-logo-24px.png` | 24 x 25. Reference only; the shipped 24 px icon is re-rendered from the vector |
| `favicon-src/cloud-logo-32px.png` | 32 x 33. Reference only, as above |
| `zozo-mascot.png` | The CRT mascot. Kept for merch; not used on the homepage |
