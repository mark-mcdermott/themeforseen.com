# Fonts

Latin subsets of variable fonts, copied from the Fontsource packages of the
same names. All are under the SIL Open Font License 1.1.

| File | Family | Role |
|---|---|---|
| `geist-latin.woff2` | Geist | headlines |
| `inter-latin.woff2` | Inter | body |
| `m-plus-1-code-latin.woff2` | M PLUS 1 Code | the machine's lettering |
| `eb-garamond-latin.woff2` | EB Garamond | the night window's headline |

The wordmark is not a font at run time. It is outlined from Sofia Sans Extra
Condensed 900 by `scripts/outline-wordmark.mjs`.
